# Контент-платформа (content2)

Веб-система керування контент-планом і **ШІ-генерацією постів** для соцмереж, з мульти-
проєктною моделлю. Наступне покоління старого «Content Planner» — тепер на Next.js + Postgres,
із живим під'єднанням до векторної бази знань і ШІ-агентів системи воронок.

**Порт:** `3001` (локально) · прод `https://content2.fineko.space` · Next.js + Prisma · БД `fineko_content2`.
Детальніші доки — у [`docs/`](docs/) (див. `SYSTEM_DESCRIPTION.md`, `tz-final-v2.md`,
`архітектура-v2-цільова.md`) та [`документація/`](документація/).

## Що вміє
- **Календар контент-плану** по проєктах і мережах, статуси постів (draft/scheduled/published).
- **ШІ-генерація постів** — контент-агент воронки `content-manager-v2` через інструменти
  дістає дані звідси (`/api/agent-tools`) і повертає готові пости (`/api/posts/bulk-import`).
- **Конструктор постів** — атоми на групі постів: hook A/B, структура, тип докази/кейс,
  формат, тема, наміри, скори. `PostModal` дозволяє поміняти тему й перегенерувати, тримаючи
  решту параметрів.
- **Модель мережа → формат → медіа** — на кожну соцмережу свої правила, доступні формати
  (`post/story/reel/carousel/thread/short/slideshow`), типи медіа й місце посилання.

## Розділи (`src/app/(dashboard)`)
`products` (продукти) · `personas` (персони/аватари) · `topics` (теми) · `structures`
(структури постів) · `networks` (соцмережі + правила/формати) · `lead-magnets` · `storage`
(сховище медіа) · `stats` (скоринг/аналітика) · `tools` · `user-data` · `admin`.

## Канонічна база генерації
7 канонічних документів = база контент-плану: продукти, персони+ToV, стратегія, теми, кейси,
лід-магніти, brand-core. Сирі онбординг-доки — **не** в базі генерації (лишаються у векторі +
відокремлені в UI).

## ШІ та інтеграції (`/api/agent-tools`)
Екшни для контент-агента: `get_products / get_personas / get_cases / get_strategy /
get_topics / get_structures / get_network_rules / get_formats / get_writing_core /
check_writing / query_vector / get_top_patterns`.
- **Векторна база** — `query_vector` проксить у вектор-сервіс (стиль автора, факти, кейси).
- **Глобальний стандарт письма** — `get_writing_core` (always-on анти-ШІ правила) +
  `check_writing` (критик-гейт).
- **Case integrity** — вигаданий кейс не просочується (даунгрейд у story, якщо назва не
  збігається з реальним Case).

## Запуск
```bash
npm install
# .env.local: DATABASE_URL, NEXTAUTH_*, WEBHOOK_SECRET, SMTP_* (пошта), VECTOR_*
npx prisma generate           # обов'язково після змін схеми (build цього не робить)
npm run dev                   # http://localhost:3001
```

## Автоматизація
- Крон `fill-skeletons` (J-2): наповнює скелети-пости повним текстом через контент-агента.
- SMTP-мейлер (`src/lib/mail.ts`) — інвайти/скид пароля.
