# Аватар (обличчя бренду): що де

Аватар це вигаданий персонаж компанії (для KIRO це Кіра), який веде соцмережі від свого імені. Платформа знає, як він виглядає, як говорить, що можна міняти в нових фото й відео, і робить усі нові фото й відео саме з нього.

## Де це в платформі

| Що | Де |
|---|---|
| Картка аватара, правила, фото-референси | меню **Аватар** (`/avatar`) |
| Усі фото й відео (референси, нові, готові ролики) | **Сховище**, папки `avatar` (референси) і `avatar-generated` (створене) |
| Голос і характер, правила постів | у картці аватара, блок «Голос і характер». Content Manager читає його у кожному пості (`get_rules` додає картку аватара) |
| Повний бриф для воронок | `get_avatar` (агент-інструменти) і `POST /api/webhooks/avatar-context` |

## Як працює

1. **Фото-референси** лежать у папці `avatar` з тегами (`ref`, `shot:portrait|laugh|fullbody|…`). Перше фото в списку «основне» (★ на сторінці).
2. **Нове фото**: воронка Flows `avatar-photo` бере референси й готовий промпт із content2, малює fal nano-banana, кладе результат у Сховище (або в пост). Приклад запуску: `POST /webhook/bot/avatar-photo` з `{projectId, scene (EN), shot, aspect, outfit?, topic?, count?}`. Ціна ≈ 4 центи за кадр.
3. **Відео**: якщо в компанії є активний аватар, КОЖНЕ замовлення на відео (`content-short-video`) автоматично отримує `avatar:true` (код `withAvatarParams`). Кадри робляться з референсів (не мультяшка), живий рух Kling, музика fal. Сцена описує, що робить Кіра: `visual` (EN), `shot`, `topic`, `motion:"ai"` + `motionPrompt`. Щоб вимкнути для одного відео: `funnel_params.avatar=false`. Ціна ≈ $1.2 за ролик 16 с (до 5 живих сцен).
4. **Фото-рілс із музикою** (готові фото замість генерації): сцени з `imageUrl`, музика fal. Ціна ≈ $0.05. Нагадування: каталог музики Instagram через API недоступний, тому музика створюється окремо й вшивається у відео.
5. **Сторіз**: воронка `avatar-story` (фото 9:16 + текст через slide-builder) або картка події, яку генерує сам KIRO (`/api/v1/events/<id>/share-image`). Публікація: пост формату «Сторіз» (`formatKey story`) → `content-scheduler` → `publish-instagram` (media_type STORIES). Посилання-стікер Instagram API не дозволяє, тому посилання на подію лежить у тексті поста як нагадування для ручного стікера.
6. **Озвучка** (ElevenLabs) закладена в сервіс відео (`speech` + ключі `ELEVENLABS_*` у воронці `content-short-video`), але ключ у платформі зараз має ліміт 10 кредитів. Щоб ввімкнути: підняти ліміт ключа «Ключ для воронок» у ElevenLabs.

## Правила аватара

Живуть у картці аватара (редагуються там же). Заготовка Кіри: `src/lib/avatar.ts` (`KIRA_DEFAULT`); оновити тексти з заготовки: `POST /api/webhooks/avatar-context {action:"reset_texts", preset:"kira"}`.

## Служебні інструменти

- `POST /api/webhooks/avatar-context` (секрет у `x-webhook-secret`): `context`, `save_media`, `ensure`, `reset_texts`.
- `POST /api/webhooks/project-admin` `attach_media`: прикріпити фото/відео зі Сховища (або картку події KIRO) до поста за номером.
- Тести: `src/lib/avatar.test.ts`; публікатори: `platform/scripts/autopost/test-publishers.js` (у репо Flows).

## Обмеження (чесно)

- Instagram API не вміє: вибрати музику з каталогу Instagram, додати стікер-посилання у сторіз.
- Інші люди в кадрі щоразу нові: нейромережа не тримає їхні обличчя між сценами.
- Руки з флаєром у русі найскладніше: дивимося кожен ролик перед публікацією.
